## Project: Maven Toys KPI Dashboard

### Overview

A report based on the Maven Toys retail dataset, developed following the LinkedIn Learning guided project **Build an Interactive Business KPI Dashboard with Power BI**.

The repository includes the Power BI file, source-data archive and report previews. It does not implement a real-time data feed.

### Repository Contents

| File | Content |
|---|---|
| `PROJECT_POWERBI_001_MAVEN_TOYS.pbix` | Power BI report |
| `PROJECT_POWERBI_001_MAVEN_TOYS.pdf` | Exported report |
| `PROJECT_POWERBI_001_MAVEN_TOYS_Screenshot.png` | Preview image |
| `PROJECT_POWERBI_001_MAVEN_TOYS_video.mp4` | Demonstration video |
| `PROJECT_POWERBI_001_MAVEN_TOYS_Maven Toys Data.zip` | Source-data archive |
| `LICENSE` | Repository license |

All these files are in the repository root.

---

## How to Use

1. Download the repository.
2. Open the `.pbix` file in Power BI Desktop on Windows.
3. Extract the source-data archive and update local file paths if needed to refresh the report.

On macOS, view the PDF, image or video. Power BI Desktop is a Windows application.
